# SARWA Admin Guide

A non-technical admin can manage the entire storefront from the panel.

## Quick Tasks

### Add a product
1. **Products → New**
2. Fill name, slug, SKU, short & full description.
3. Set price and optional offer price.
4. Pick category, sub-category, collection, fabric, occasion, color.
5. Add tags and mark flags (Featured / Trending / New / Best Seller).
6. Upload images (multiple, zoom-enabled) and optional video.
7. Add variants (size + stock per variant).
8. SEO tab: title, description, keywords.
9. Save as Draft or Publish.

### Edit hero slider
1. **Hero Slider → New Banner**
2. Upload desktop & mobile images (recommended 1920×900 and 750×1000).
3. Heading, sub-heading, CTA label & link.
4. Set display order.
5. Enable / disable.
6. Optionally schedule via start/end dates.

### Mega menu builder
1. **Menus → Edit**
2. Add menu items via drag/drop (unlimited depth).
3. Click a node to attach products and categories.
4. Reorder via handle, toggle visibility, save.
5. Preview storefront mega menu live.

### Manage orders
- Open **Orders → Order Detail**.
- Update statuses: Pending → Confirmed → Shipped → Delivered.
- Add timeline entries (auto + manual).
- Issue refund or accept return from the action menu.

### Coupons
- **Coupons → New**. Choose percentage or flat. Set min purchase, usage limit, per-customer limit, expiry.
- Apply per user or per first order.

### Roles & permissions
- **Users → Roles**. Default roles:
  - **Admin** — full access
  - **Manager** — operations without user management
  - **Editor** — products, content, menus
  - **Staff** — orders & customers only
